# Escrever spec

1. Ler `docs/principios.md` e specs vizinhas para não duplicar.
2. Criar `docs/specs/SPEC-NN-nome.md` com objetivo, regras, critérios de aceite e testes.
3. Não inventar regra que não esteja no pedido ou em `docs/banco.md`.
4. Dúvida: perguntar.
